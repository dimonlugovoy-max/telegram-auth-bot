# Telegram Auth Bot

Бот для аутентификации клиентов через Telegram с автоматической синхронизацией в YClients.

## ✅ Функции

- Генерация одноразовых ссылок с HMAC-подписью
- Сбор ФИО и согласия на обработку данных
- Синхронизация с YClients API
- Поддержка повторных попыток
- API для интеграции
- HTTPS через Let's Encrypt
